# Next.js Проект

Next.js 16, TypeScript и архитектуре Feature-Sliced Design.

## Возможности

- Мультиязычность (Английский/Русский)
- Авторизация с сохранением сессий
- Адаптивный дизайн
- Архитектура FSD
- Пакетный менеджер Bun

## Начало работы

### Установка зависимостей

```bash
bun install
```

### Разработка

Запуск dev-сервера:

```bash
bun dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка

Сборка:

```bash
bun build
```

## Структура проекта

```
src/
├── app/              # App router
├── entities/         # Бизнес-сущности
├── features/         # Фичи
├── widgets/          # Виджеты
├── shared/           # Общий код
│   ├── api/          # API слой
│   ├── config/       # Конфигурации
│   ├── lib/          # Утилиты и хелперы
│   ├── styles/       # Глобальные стили
│   └── ui/           # UI компоненты
└── proxy.ts          # proxy для защиты роутов
```

## Доступные команды

- `bun dev` - Запуск dev сервера
- `bun build` - Сборка для prod
- `bun start` - Запуск prod сервера
- `bun lint` - Запуск ESLint

## Локализация

Приложение поддерживает два языка:

- Английский (en)
- Русский (ru)

Язык сохраняется в cookies и может быть изменён через переключатель языка в хедере

## Авторизация

Приложение имеет простую систему авторизации. Используйте любой email и пароль для входа. Состояние авторизации сохраняется в cookies через Zustand middleware.

## Предложения по улучшению проекта

1. **Миграция на NextAuth**
   - Замена текущей системы авторизации на NextAuth для поддержки JWT токенов и улучшенной безопасности

2. **Server side валидация**
   - Добавление валидации данных на сервере через Server Actions
   - Использование Zod схем для валидации входящих данных
   - Защита от небезопасных данных с клиента

3. **React Suspense и Loading States**
   - Добавление `loading.tsx` файлов для страниц
   - Использование Suspense boundaries для асинхронных компонентов
   - Интеграция скелетонов для лучшего восприятия загрузки

4. **Error Handling**
   - Добавление `error.tsx` для обработки ошибок на уровне страниц
   - Реализация Error Boundary

5. **Интеграция библиотеки для уведомлений**

6. **Тестирование**
   - Vitest - unit тестирование компонентов и утилит
   - Testing Library - тестирование React компонентов
   - Storybook - изолированная разработка и документация UI компонентов

7. **Линтинг и конфиги**
   - Интеграция Prettier и настройка конфига под нужды проекта
   - Настройка конфига ESLint под нужды проекта
   - Настройка конфига NextConfig под нужды проекта
   - Настройка конфига TSConfig под нужды проекта
